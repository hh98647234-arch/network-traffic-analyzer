# Network Traffic Analyzer
## Project Overview
A python-based cybersecurity project designed to analyze network traffic logs, monitor IP addresses and ports, and identify repeated network connections.
## Features
- Analyzes network traffic logs
- Counts total network connections
- Tracks source IP addresses
- Monitors TCP and UDP ports activity
- Generates alerts for repeated IP activity
- Display a network traffic analysis report
## Technologies Used
- Python 3
- VS code
- GitHub
- Python collections.counter
## How to run
1. Download the repository files.
2. Keep traffic_analyzer.py and network_logs.txt in the same folder.
3. Open a terminal in that folder.
4. Run: python traffic_analyzer.py
## Sample output

ALERT: Repeated traffic from 192.168.1.25
Port 443: 2 connections
Port 53: 2 connections
Port 22: 4 connections
## Cybersecurity Skills Demonstrated
- Network traffic analysis
- Log monitoring
- IP address tracking
- Port analysis
- Basic anomaly detections
## Note
This project uses sample network logs for educational purposes. Repeated traffic does not necessarily indicate an attack.
